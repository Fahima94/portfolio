# Portfolio — Fahima Behillil

Site statique (HTML + CSS + un fichier JS), sans dépendance ni build. Prêt pour GitHub Pages.

## Mise en ligne en 3 étapes
1. Créer un dépôt public `portfolio` et y déposer `index.html`, `styles.css`, `script.js`, `assets/` (la racine du dépôt, pas de sous-dossier).
2. Settings → Pages → Source : `Deploy from a branch`, branche `main`, dossier `/ (root)`.
3. Le site est en ligne sur `https://fahima94.github.io/portfolio/` en une à deux minutes.

## Photo
Placer votre portrait recadré (buste, fond neutre) dans `assets/portrait.jpg`.
Sans photo, un monogramme FB s'affiche proprement — le site reste présentable.

## Domaine
Un nom de domaine (ex. fahima-behillil.fr) se branche via Settings → Pages → Custom domain.

## À personnaliser
- Les liens projets pointent vers vos dépôts GitHub : vérifier chaque URL.
- Le titre et l'accroche du hero.
- Les chiffres du bloc statistiques.
